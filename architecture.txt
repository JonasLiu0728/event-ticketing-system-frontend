## 已知問題與修正

| 問題 | 狀態 | 說明 |
|------|------|------|
| `EditEventPage.toDatetimeLocal` | ✅ 已修正 | 原本直接 slice UTC 字串，時間差 8 小時；改用 `new Date(iso)` 轉本地時間 |
| `raceCondition.spec.ts` URL 缺 `https://` | ✅ 已修正（或刪除） | `Ticketrace.spec.ts` 已覆蓋相同情境 |
| `remainingTickets` 後端不即時遞減 | ⚠️ 後端問題 | 即時票數只在 EventDetailPage 透過 `checkEligibility` API 取得 |
| 孤兒票券/報名（Unknown Event） | ✅ 前端已處理 | `isOrphanRecord()` 過濾，UI 不顯示 |
| `cancellationDeadline` 後端未回傳 | ⚠️ 後端問題 | 前端 fallback 用 `eventStartTime` 判斷 |
| HR 票券/報名 API 被擋 | ⚠️ 後端問題 | `GET /tickets` / `POST /transactions` 只允許 employee |

## 重要業務邏輯

### 報名流程
```
checkEligibility → eligible=true, isWaitlist=false → 立即報名
                 → eligible=true, isWaitlist=true  → 加入候補
                 → eligible=false, reason=LOCKED   → 帳號鎖定
                 → eligible=false, reason=ALREADY_REGISTERED → 已報名
createTransaction → status=confirmed → 報名成功
                 → status=waitlist   → 票被搶走，進候補
                 → 409 NO_TICKETS   → 差一點，進候補
```

### 票券狀態
```
invalid  → 活動未開始（未開放）
unused   → 活動進行中，可報到
used     → 已核銷
```

### 取消資格
```ts
canCancel(tx):
  status !== "confirmed" → false
  有 cancellationDeadline → 比對現在時間
  無 cancellationDeadline → 比對 eventStartTime
```

### 活動時間限制（validateEventForm）
```
registrationEnd 只需要 <= eventEndTime（不是 eventStartTime）
這讓「活動進行中仍可報名」成為可能
```
